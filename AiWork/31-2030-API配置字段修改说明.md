## 使用场景说明

### 可以不填的场景

#### base_url 不填

- ✅ 使用 Provider 驱动的默认地址
- ✅ OpenAI Provider: 自动使用 `https://api.openai.com`
- ✅ Anthropic Provider: 自动使用 `https://api.anthropic.com`
- ✅ 适合使用官方 API 的标准场景

#### api_key 不填

- ✅ 创建测试渠道占位
- ✅ 禁用渠道作为备份
- ⚠️ 计划继承父渠道配置（继承功能未实现）

### 必须填写场景

#### 启用渠道

- ❌ 必须配置 `api_key`
- ⚠️ `base_url` 可选（使用默认地址）

#### 自定义上游

- ❌ 必须配置 `base_url`
- 例如：Azure、自定义端点

#### 测试渠道

- ❌ 必须配置 `api_key`
- ⚠️ `base_url` 可选

## Provider 默认地址

各 Provider 驱动的默认地址：

| Provider | 默认地址 | 端点 |
|----------|---------|------|
| OpenAI | `https://api.openai.com` | `/v1/chat/completions` |
| Anthropic | `https://api.anthropic.com` | `/v1/messages` |
| DeepSeek | `https://api.deepseek.com` | `/v1/chat/completions` |
| Azure | ⚠️ 无默认，必须配置 | `/openai/deployments/{deployment}` |

**实现方式**：

```php
// AbstractProvider.php
public function __construct(array $config = [])
{
    $this->baseUrl = $config['base_url'] ?? $this->getDefaultBaseUrl();
    $this->apiKey = $config['api_key'] ?? '';
}

// OpenAIProvider.php
public function getDefaultBaseUrl(): string
{
    return 'https://api.openai.com';
}
```

## 建议

### 当前版本（继承未实现）

- ✅ **base_url**：使用官方 API 时可以不填
- ✅ **api_key**：启用渠道时必须配置
- ⚠️ 不依赖继承，每个渠道完整配置

### 未来版本（继承实现后）

- ✅ 子渠道可以不填 `base_url` 和 `api_key`
- ✅ 从父渠道继承配置
- ✅ 支持多级继承

## 验证测试

### 后台测试

1. 创建渠道时不填 `base_url`
2. 选择 Provider（如 OpenAI）
3. 保存成功
4. 查看详情，验证使用默认地址

### API 测试

```bash
# 使用 tinker 测试
php artisan tinker

$channel = Channel::create([
    'name' => 'Test Channel',
    'slug' => 'test-channel',
    'provider' => 'openai',
    'base_url' => null,  // 不填
    'api_key' => 'sk-xxx',
]);

$channel->base_url;  // null

// Provider 初始化时使用默认值
$provider = new OpenAIProvider([
    'base_url' => $channel->base_url,
    'api_key' => $channel->api_key,
]);

$provider->baseUrl;  // "https://api.openai.com"
```
