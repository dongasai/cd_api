# 渠道模型继承缺口修复报告

**修复时间**: 2026-07-31  
**修复文件**: `app/Services/Router/ChannelRouterService.php`

---

## 问题描述

`ChannelInheritanceResolver` 已实现 `resolveChannelModels()` 方法来解析继承后的模型列表，但 `ChannelRouterService` 中的两个关键方法**直接查询数据库**，完全绕过了继承解析。

---

## 缺口 1: `getChannelIdsForModel()` 修复

### 问题

```php
// 修复前：直接查询数据库
return ChannelModel::where('model_name', $model)
    ->where('is_enabled', true)
    ->pluck('channel_id')
    ->toArray();
```

**问题**：子渠道如果没有自己的 `channel_models` 记录，即使通过继承获得了该模型支持，也不会被选中。

### 修复方案

```php
// 修复后：支持继承
// 1. 直接拥有该模型的渠道
$directChannelIds = ChannelModel::where('model_name', $model)
    ->where('is_enabled', true)
    ->pluck('channel_id')
    ->toArray();

// 2. 通过继承获取该模型的渠道
$inheritedChannelIds = [];
$childChannels = Channel::whereNotNull('parent_id')
    ->where('parent_id', '!=', 0)
    ->whereNotIn('id', $directChannelIds)
    ->get();

foreach ($childChannels as $channel) {
    $effectiveModels = $channel->getEffectiveChannelModels();
    foreach ($effectiveModels as $effectiveModel) {
        if ($effectiveModel['model_name'] === $model && $effectiveModel['is_enabled']) {
            $inheritedChannelIds[] = $channel->id;
            break;
        }
    }
}

return array_unique(array_merge($directChannelIds, $inheritedChannelIds));
```

## 缺口 2: `resolveModel()` 修复

### 问题

```php
// 修复前：直接查询当前渠道的 channel_models
$channelModel = ChannelModel::where('channel_id', $channel->id)
    ->where('model_name', $modelName)
    ->where('is_enabled', true)
    ->first();
```

**问题**：子渠道无法获取继承来的模型映射。

### 修复方案

```php
// 修复后：三级查找
// ① 渠道自身 channel_models（别名匹配）
foreach ($modelNames as $modelName) {
    $channelModel = ChannelModel::where('channel_id', $channel->id)
        ->where('model_name', $modelName)
        ->where('is_enabled', true)
        ->first();
    
    if ($channelModel) {
        return $channelModel->mapped_model ?? $modelName;
    }
}

// ② 继承模型列表（有父渠道时）
if ($channel->hasParent()) {
    $effectiveModels = $channel->getEffectiveChannelModels();
    foreach ($modelNames as $modelName) {
        foreach ($effectiveModels as $effectiveModel) {
            if ($effectiveModel['model_name'] === $modelName && $effectiveModel['is_enabled']) {
                return $effectiveModel['mapped_model'] ?? $modelName;
            }
        }
    }
}

// ③ 渠道自身 channel_models（原模型名匹配，兜底）
$channelModel = ChannelModel::where('channel_id', $channel->id)
    ->where('model_name', $model)
    ->where('is_enabled', true)
    ->first();

if ($channelModel && $channelModel->mapped_model) {
    return $channelModel->mapped_model;
}

// ④ 返回原模型名
return $model;
```

## 向后兼容性

✅ **完全向后兼容**

- 无父渠道时（`hasParent()` 返回 false），跳过继承查找，行为与修复前完全一致
- 有父渠道时，优先使用渠道自身配置，仅在自身未配置时才使用继承

---

## 性能影响

**可接受范围**

- `getChannelIdsForModel()`: 新增查询所有子渠道（通常数量有限，< 100）
- `resolveModel()`: 仅在自身未配置时调用 `getEffectiveChannelModels()`
- 暂不做缓存优化（子渠道数量有限，影响可控）
