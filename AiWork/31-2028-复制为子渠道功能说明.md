# 复制为子渠道功能说明

## 功能概述

新增 `CopyAsChildChannel` 操作，用于将当前渠道复制为子渠道，自动建立父子继承关系。

## 实现位置

- **Action 类**：`app/Admin/Actions/Channel/CopyAsChildChannel.php`
- **控制器注册**：`app/Admin/Controllers/ChannelController.php`
- **语言包**：`lang/zh_CN/admin-actions.php` 和 `lang/en/admin-actions.php`

## 核心功能

### 1. 自动设置父子关系

```php
$newChannel->parent_id = $parentId;  // 设置父渠道 ID
$newChannel->inherit_mode = 'merge'; // 默认使用合并继承
```

### 2. 智能命名

- 名称格式：`{父渠道名} (子渠道)`
- Slug 格式：`{父渠道slug}_child_{序号}_{时间戳}`
- 自动避免重复

### 3. 重置统计信息

复制的子渠道会重置以下字段：
- success_count = 0
- failure_count = 0
- total_requests = 0
- total_tokens = 0
- total_cost = 0
- avg_latency_ms = 0
- success_rate = 1.0
- status2 = 'normal'
- status2_remark = null

### 4. 复制模型配置

自动复制父渠道的所有 `channel_models` 关联数据。

## 使用方式

### 在后台列表页

访问 `/admin/channels`，每个渠道行操作中会显示：

```
[查看] [复制] [复制为子渠道] [原生测试] [中转测试]
```

点击"复制为子渠道"按钮，确认后即可创建子渠道。

### 操作流程

1. 点击"复制为子渠道"按钮
2. 弹出确认对话框：
   - 标题："确认复制为子渠道?"
   - 说明："将创建一个子渠道副本，自动设置父渠道ID，继承模式默认为merge（合并继承），统计信息将重置为零。"
3. 确认后创建子渠道
4. 成功提示："子渠道创建成功！父渠道：{父渠道名}，子渠道：{子渠道名}"

## 与普通复制的区别

| 功能 | 复制（CopyChannel） | 复制为子渠道（CopyAsChildChannel） |
|------|-------------------|-----------------------------------|
| parent_id | 保持原值（可能为 NULL） | 设置为当前渠道 ID |
| inherit_mode | 保持原值 | 强制设置为 'merge' |
| 名称后缀 | (复制) | (子渠道) |
| Slug 后缀 | _copy_{时间戳} | _child_{序号}_{时间戳} |
| 健康状态 | 保持原值 | 重置为 normal |
| 用途 | 创建独立副本 | 创建继承关系的子渠道 |

## 继承模式说明

默认使用 `merge`（合并继承）模式：

- **数组类型**：合并父子数组（去重）
- **对象类型**：深度合并，子覆盖父
- **标量类型**：子覆盖父

**示例**：

```php
// 父渠道
base_url: "https://api.openai.com"
api_key: "sk-xxx"
models: ["gpt-4", "gpt-3.5-turbo"]
config: {timeout: 120}

// 子渠道（复制后可修改）
weight: 5         // 子渠道特有
priority: 1        // 子渠道特有
models: ["gpt-4"] // 覆盖或合并模型列表

// 实际使用时（如果继承功能实现）
// base_url、api_key 从父渠道继承
// models 合并或覆盖
// config 深度合并
```

## 重要提示

⚠️ **继承功能状态**：

当前版本数据库结构支持继承配置，但**继承解析逻辑尚未实现**。

- ✅ 可以创建子渠道并设置 `parent_id` 和 `inherit_mode`
- ❌ 实际运行时不会应用继承逻辑
- ⚠️ 子渠道仍需完整配置所有字段（base_url, api_key 等）

**建议**：
- 当前版本：子渠道需要完整配置，不能依赖继承
- 未来版本：实现 `ChannelInheritanceService` 后，子渠道可以继承父渠道配置

## 测试建议

### 手动测试

1. 创建一个基础渠道作为父渠道
2. 在列表页点击"复制为子渠道"
3. 验证创建的子渠道：
   - `parent_id` 是否正确指向父渠道
   - `inherit_mode` 是否为 'merge'
   - 名称和 slug 格式是否正确
   - 统计信息是否已重置
   - 健康状态是否为 'normal'
   - 模型配置是否已复制

### 验证查询

```php
// 在 tinker 中验证
php artisan tinker

// 查看子渠道
$child = Channel::whereNotNull('parent_id')->first();
$child->parent_id;      // 应该有值
$child->inherit_mode;   // 应该是 'merge'

// 查看父子关系
$parent = Channel::find($child->parent_id);
$parent->children;      // 应该包含子渠道
$child->parent;         // 应该指向父渠道
```

## 后续优化建议

1. **继承解析实现**：优先实现 `ChannelInheritanceService`
2. **循环检测**：防止创建循环继承（A→B→A）
3. **层级限制**：限制继承链最大深度（建议 5 级）
4. **批量操作**：支持批量复制多个渠道为子渠道
5. **模板继承**：支持选择继承模板，而非完全复制
