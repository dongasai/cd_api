# HTTP 请求头解析

## Claude CLI 相关请求头

### `user-agent: claude-cli/2.1.220 (external, cli)`
- **含义**: 标识客户端类型和版本
- **解析**: Claude Code CLI 工具，版本 2.1.220，外部调用，CLI 模式

### `anthropic-beta`
- **含义**: 启用的 Anthropic API Beta 功能特性列表
- **解析**: 启用了以下 Beta 功能：
  - `claude-code-20250219` - Claude Code 功能
  - `interleaved-thinking-2025-05-14` - 交错思考模式
  - `redact-thinking-2026-02-12` - 思考内容脱敏
  - `thinking-token-count-2026-05-13` - 思考 Token 计数
  - `context-management-2025-06-27` - 上下文管理
  - `prompt-caching-scope-2026-01-05` - Prompt 缓存作用域
  - `mid-conversation-system-2026-04-07` - 对话中系统消息
  - `effort-2025-11-24` - 推理努力级别

### `anthropic-dangerous-direct-browser-access: true`
- **含义**: 允许危险的直接浏览器访问
- **解析**: 允许 CLI 工具直接访问浏览器相关功能（如 Playwright）

### `anthropic-version: 2023-06-01`
- **含义**: Anthropic API 版本号
- **解析**: 使用 2023-06-01 版本的 API 规范

### `x-app: cli`
- **含义**: 应用类型标识
- **解析**: 标识请求来自 CLI 应用

### `x-claude-code-session-id: b3985026-a957-4fa0-b998-bedc72b293b0`
- **含义**: Claude Code 会话 ID
- **解析**: UUID 格式的会话唯一标识符，用于追踪整个会话生命周期

## 代理相关请求头（Traefik 反向代理）

### `x-forwarded-for: 10.42.0.1`
- **含义**: 客户端真实 IP 地址
- **解析**: 请求原始来源 IP 为 10.42.0.1（内网地址）

### `x-forwarded-host: httpdemo.s1.xiaobei.fun`
- **含义**: 客户端请求的原始主机名
- **解析**: 请求的域名是 httpdemo.s1.xiaobei.fun

### `x-forwarded-port: 443`
- **含义**: 客户端请求的原始端口
- **解析**: 使用 HTTPS 标准端口 443

### `x-forwarded-proto: https`
- **含义**: 客户端使用的协议
- **解析**: 使用 HTTPS 加密协议

### `x-forwarded-server: traefik-9bcdbbd9-72gb6`
- **含义**: 处理请求的代理服务器标识
- **解析**: Traefik 反向代理服务器实例 ID

### `x-real-ip: 10.42.0.1`
- **含义**: 客户端真实 IP（Nginx 风格）
- **解析**: 与 `x-forwarded-for` 相同，表示客户端真实 IP

## Stainless SDK 相关请求头

Stainless 是一个用于生成 SDK 的工具，这些请求头来自 Anthropic 的官方 Node.js SDK。

### `x-stainless-arch: x64`
- **含义**: 系统架构
- **解析**: 运行在 x64（64位）架构上

### `x-stainless-lang: js`
- **含义**: 编程语言
- **解析**: 使用 JavaScript

### `x-stainless-os: Linux`
- **含义**: 操作系统
- **解析**: 运行在 Linux 系统上

### `x-stainless-package-version: 0.94.0`
- **含义**: SDK 包版本
- **解析**: Anthropic SDK 版本为 0.94.0

### `x-stainless-retry-count: 0`
- **含义**: 重试次数
- **解析**: 当前请求是首次尝试，没有重试

### `x-stainless-runtime: node`
- **含义**: 运行时环境
- **解析**: 使用 Node.js 运行时

### `x-stainless-runtime-version: v26.3.0`
- **含义**: 运行时版本
- **解析**: Node.js 版本为 v26.3.0

### `x-stainless-timeout: 600`
- **含义**: 请求超时时间
- **解析**: 设置 600 秒（10 分钟）超时

---

## 标准请求头

### `content-type: application/json`
- **含义**: 内容类型
- **解析**: 请求体为 JSON 格式

### `accept-encoding: gzip`
- **含义**: 接受的编码方式
- **解析**: 客户端支持 GZIP 压缩响应

---

## 总结

这些请求头完整描述了：
1. **客户端信息**: Claude CLI 2.1.220 + Node.js v26.3.0 + Anthropic SDK 0.94.0
2. **API 特性**: 启用了多个 Beta 功能，包括思考脱敏、上下文管理等
3. **网络路径**: 通过 Traefik 反向代理（HTTPS）访问服务
4. **会话追踪**: 通过 session ID 追踪整个会话
5. **超时配置**: 10 分钟超时，适用于长时间 AI 对话

这些请求头对于 CdApi 项目具有重要意义：
- 可以用于日志记录和审计
- 可以识别客户端类型（CLI vs Web）
- 可以追踪会话和请求链路
- 可以根据客户端能力调整响应格式
