# 测试数据库安全配置

## 问题：测试可能清空生产数据库

### 场景
```php
// 测试类使用 RefreshDatabase trait
class ExampleTest extends TestCase
{
    use RefreshDatabase;  // 会清空数据库！

    public function test_example()
    {
        // 如果连接到生产数据库，数据将被清空！
    }
}
```

## 🔒 三层防护机制

### 第 1 层：强制内存数据库

**phpunit.xml**（最高优先级）：
```xml
<!-- force="true" 确保无法被 .env 覆盖 -->
<env name="DB_CONNECTION" value="sqlite" force="true"/>
<env name="DB_DATABASE" value=":memory:" force="true"/>
```

**效果**：
- ✅ 即使 `.env` 配置了 MySQL，测试仍使用内存数据库
- ✅ 测试结束后数据自动释放
- ✅ 无法连接到生产数据库

### 第 2 层：环境名称检查

**TestCase.php**：
```php
protected function setUp(): void
{
    parent::setUp();

    $database = config('database.connections.'.$connection.'.database');

    // 禁止包含生产数据库名特征
    if (str_contains($database, 'cdapi')) {
        $this->fail("测试禁止连接生产数据库");
    }

    // 只允许测试数据库
    if (!str_contains($database, ':memory:|testing|test_')) {
        $this->fail("测试只能使用测试数据库");
    }
}
```

**效果**：
- ✅ 在测试运行前检查数据库名
- ✅ 发现危险连接立即失败
- ✅ 提示清晰的安全错误

### 第 3 层：数据库用户权限

**创建测试专用用户**：
```sql
-- 测试用户只能访问测试数据库
CREATE USER 'cdapi_test'@'%' IDENTIFIED BY 'TestPassword123!@#';
GRANT ALL PRIVILEGES ON cdapi_test.* TO 'cdapi_test'@'%';
GRANT ALL PRIVILEGES ON test_cdapi.* TO 'cdapi_test'@'%';

-- 无权访问生产数据库
-- cdapi_test 用户对 cdapi 数据库没有任何权限
```

**测试配置**（如果必须使用 MySQL）：
```env
# .env.testing
DB_CONNECTION=mysql
DB_DATABASE=cdapi_test
DB_USERNAME=cdapi_test
DB_PASSWORD=TestPassword123!@#
```

**效果**：
- ✅ 即使配置错误，也无法访问生产数据库
- ✅ 测试用户只能看到测试数据库

## 📋 完整配置

### phpunit.xml
```xml
<php>
    <!-- 强制使用内存数据库 -->
    <env name="DB_CONNECTION" value="sqlite" force="true"/>
    <env name="DB_DATABASE" value=":memory:" force="true"/>
</php>
```

### tests/TestCase.php
```php
protected function setUp(): void
{
    parent::setUp();
    $this->ensureNotProductionDatabase();
}

protected function ensureNotProductionDatabase(): void
{
    $database = config('database.connections.'.config('database.default').'.database');

    // 禁止生产数据库名
    if (str_contains($database, 'cdapi')) {
        $this->fail("测试禁止连接生产数据库：{$database}");
    }

    // 只允许测试数据库
    $allowed = ['memory:', 'testing', 'test_', '_test'];
    foreach ($allowed as $pattern) {
        if (str_contains($database, $pattern)) {
            return; // 安全
        }
    }

    $this->fail("测试只能使用测试数据库");
}
```

### .env.testing
```env
# 测试环境强制使用独立数据库
DB_CONNECTION=sqlite
DB_DATABASE=:memory:
```

## 🧪 验证测试安全

### 测试 1：检查数据库连接
```bash
php artisan tinker
>>> DB::connection()->getDatabaseName();
=> "cdapi"  // 生产数据库

# 运行测试
php artisan test

# 测试中检查
>>> DB::connection()->getDatabaseName();
=> ":memory:"  // 内存数据库
```

### 测试 2：验证安全检查
```php
// tests/Feature/DatabaseSafetyTest.php
public function test_prevents_production_database()
{
    // 临时修改配置模拟错误
    config(['database.connections.sqlite.database' => 'cdapi']);

    // 应该抛出安全错误
    $this->expectException(\Exception::class);
    $this->expectExceptionMessage('测试禁止连接生产数据库');

    // 会触发安全检查
    $response = $this->get('/api/test');
}
```

### 测试 3：尝试清空数据库
```bash
# 即使测试代码中有 truncate，也不会影响生产数据
php artisan test --filter ExampleTest

# 检查生产数据是否完好
php artisan tinker
>>> DB::table('channels')->count();
=> 5  // 数据完好
```

## ⚠️ 危险操作检查清单

运行测试前确认：

- [ ] `phpunit.xml` 中数据库配置是 `:memory:`
- [ ] `force="true"` 属性已添加
- [ ] `TestCase.php` 包含安全检查
- [ ] `.env.testing` 配置了测试数据库
- [ ] 生产数据库有独立用户和权限
- [ ] 测试用户无权访问生产数据库

## 🎯 安全保证

| 攻击场景 | 防护效果 |
|---------|---------|
| 修改 `.env` 指向生产数据库 | ❌ 被 `phpunit.xml` 的 `force="true"` 覆盖 |
| 测试代码中硬编码连接 | ❌ 被 `TestCase::setUp()` 检查拦截 |
| 配置错误的数据库用户 | ❌ 数据库用户权限限制，无法访问生产库 |
| 直接运行测试 | ✅ 使用内存数据库，完全隔离 |

---

**核心原则**：
1. 测试永远使用内存数据库
2. 代码层面检查数据库名
3. 数据库层面限制用户权限

**这三层防护确保测试 100% 不会清空生产数据。**
