# 任务规划：数据库迁移执行列表后台

## 任务目标
在 Dcat Admin 后台增加"数据库迁移管理"功能，展示迁移列表并支持手动执行迁移。

## 当前阶段：方案审阅完成，等待批准

### 实现方案

#### 架构设计
- **数据层**：MigrationRepository（继承 `Dcat\Admin\Repositories\Repository`，合并文件系统 + migrations 表）
- **业务层**：复用 MigrationService（migrateOne, migrate）
- **展示层**：MigrationController + Grid + RowAction + BatchAction + ToolAction
- **部署层**：菜单迁移 + 翻译文件

#### 技术选型
- 数据源：自定义 Repository（继承 `Dcat\Admin\Repositories\Repository`，实现 `get()` 方法，设置 `$keyName = 'name'`）
- 行操作：继承 RowAction，实现 title() + confirm() + handle()（含 try-catch）
- 批量操作：继承 BatchAction，key 为迁移文件名字符串数组
- 工具按钮：继承 ToolAction，"执行全部待执行迁移"
- 菜单创建：数据库迁移方式（parent_id=56, order=22, icon=feather icon-database）
- 并发安全：使用 cache lock 防止并发执行

### 任务清单

#### 阶段 1: 数据层
□ **任务1：创建迁移数据仓库类**
  - 文件：`app/Admin/Repositories/MigrationRepository.php`
  - 操作：
    - 继承 `Dcat\Admin\Repositories\Repository`
    - 设置 `$keyName = 'name'`（迁移文件名作为行唯一标识）
    - 实现 `get(Grid\Model $model)` 方法：
      - 扫描 `database/migrations/*.php` 文件
      - 查询 `migrations` 表获取已执行迁移（migration, batch）
      - 合并生成状态列表：name, status(ran/pending), batch, ran_at
      - 手动处理排序和分页（LengthAwarePaginator）
      - 处理状态筛选逻辑
  - 验证：返回数据包含 name, status, batch, ran_at 字段

#### 阶段 2: 业务层
□ **任务2：创建翻译文件**
  - 文件：`resources/lang/zh_CN/admin-migration.php`
  - 操作：定义翻译键：
    - fields: name(迁移名称), status(状态), batch(批次), ran_at(执行时间)
    - labels: title(数据库迁移管理), pending(待执行), ran(已执行)
    - actions: migrate_one(执行), batch_migrate(批量执行), migrate_all(执行全部)
    - confirm: migrate_one(确定执行此迁移？), batch_migrate(确定批量执行选中的迁移？), migrate_all(确定执行全部待执行迁移？)
  - 验证：admin_trans_field() 返回正确翻译

□ **任务3：创建行操作 Action**
  - 文件：`app/Admin/Actions/MigrateOne.php`
  - 操作：
    - 继承 `Dcat\Admin\Grid\RowAction`
    - 实现 `title()`：返回按钮标题（仅对 pending 状态显示）
    - 实现 `confirm()`：返回确认对话框内容
    - 实现 `handle()`：
      - 使用 cache lock 防止并发
      - try-catch 包裹 MigrationService::migrateOne()
      - 成功返回 `$this->response()->success()->refresh()`
      - 失败返回 `$this->response()->error($e->getMessage())`
  - 验证：点击按钮弹出确认框，执行成功刷新页面

□ **任务4：创建批量操作 Action**
  - 文件：`app/Admin/Actions/BatchMigrate.php`
  - 操作：
    - 继承 `Dcat\Admin\Grid\Tools\BatchAction`
    - key 为迁移文件名字符串数组
    - 实现 `title()`、`confirm()`、`handle()`
    - 串行调用 migrateOne()，收集结果
    - 使用 cache lock 防止并发
  - 验证：选中多个迁移，批量执行成功

□ **任务5：创建"执行全部"工具按钮**
  - 文件：`app/Admin/Actions/MigrateAll.php`
  - 操作：
    - 继承 `Dcat\Admin\Grid\Tools\Action`
    - 实现 `title()`、`confirm()`、`handle()`
    - 调用 MigrationService::migrate()
    - 使用 cache lock 防止并发
  - 验证：点击按钮执行全部待执行迁移
